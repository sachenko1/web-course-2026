# Zen-Money (Лабораторная работа №8–9)

Full-stack приложение для учёта личных доходов и расходов: REST API на Node.js / Express + SQLite и клиентская часть на чистом JavaScript (ES-модули) с серверной фильтрацией и сохранением настроек интерфейса в `localStorage`.

## База данных

Файл `server/database.sqlite` добавлен в `.gitignore` и не хранится в репозитории. При первом запуске сервера база данных, таблицы `categories` и `transactions`, а также 3 стартовые категории («Еда», «Транспорт», «Зарплата») создаются автоматически.
