# Zen-Todo (Лабораторная работа №10–11)

Интерактивный менеджер задач на React (Vite) с декомпозицией на функциональные компоненты, фильтрацией по статусу («Все / Активные / Завершённые»), сортировкой без мутации состояния и сохранением списка задач и настроек в `localStorage`.

## Запуск проекта

```bash
npm install
npm run dev
