# Zen-Todo (Лабораторная работа №10–11)

Приложение списка задач на React (Vite), реализованное на функциональных компонентах и хуках (`useState`, `useEffect`).

## Реализованная функциональность

- **Компонентная структура:** интерфейс разделён на `App`, `TodoForm`, `TodoList`, `TodoItem`, `Filters` и `Stats` с передачей состояния и колбэков через `props`.
- **Работа со списком:** добавление задач с валидацией, отметка выполнения, удаление и отображение счётчиков.
- **Фильтрация и сортировка:** переключение вкладок («Все / Активные / Завершённые») и сортировка (по дате добавления и по алфавиту) без мутации исходного массива.
- **Сохранение данных:** автоматическое сохранение задач, выбранного фильтра, сортировки и темы в `localStorage` с помощью `useEffect`.
